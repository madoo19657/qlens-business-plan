Executive Summary

항목 내용
문제 비대면 파손보험은 진단 앱 설치를 요구하면 가입 이탈이 크고(업계 추정 40~50%, A10), 검증을 느슨히 하면 사전 파손 기기와 화면 녹화 재생 같은 부정 가입으로 손해율이 오른다.
해법 QLens는 알림톡 링크 한 번으로 모바일 웹에서 거울 반사 AI 진단, 터치 점검, 위·변조 방지 검증을 약 90초 안에 끝내는 B2B 진단 엔진이다. Web SDK 한 줄과 Webhook으로 연동한다.
시장 국내 연관 시장(보험 가입·중고폰 검수·수리 청구 검증)은 연 약 126억 원으로 추정A15. 초기 목표는 자급제·알뜰폰 비대면 파손보험이며 잠재 약 120만 건/년A04.
모델 건당 과금(기준 400원). 초기 구축비·고정 라이선스 없음. 건당 직접 원가 약 11원A02으로 공헌이익 389원. 청구 FDS, 중고 연계, (자격 확보 시) 보험 중개로 확장.
목표 3개년 매출 보수안 0.48 → 1.83 → 4.59억 원, 기준안 2.16 → 6.03 → 9.63억 원. 초기 12개월은 PoC 계약 확보와 핵심 지표 검증에 집중.
선결 과제 보험업법 모집 자격 확인, 파손 단말 학습 데이터 확보, 첫 PoC 파트너 확정, 고정비 현실화.

문제 정의 · 시장 기회

1.1 비대면 파손보험의 구조적 딜레마

가입이 편해질수록 사기 위험이 커지고, 검증이 엄격해질수록 가입이 줄어드는 구조다.

가입 이탈 역선택·사기
원인 전용 진단 앱 설치 요구 개통·구매 후 비대면 가입 시 기기 상태를 직접 확인할 수 없음
현상 청약 단계 이탈 사전 파손 기기 가입, 정상 폰 화면 녹화본 재생(Replay Attack)
결과 전환율 하락 초기 손해율 상승

1.2 시장 동향

  • 채널 이동: 과거에는 개통 당일 대리점에서 가입하는 오프라인이 압도적이었다(원본 대화 추정 70~80%). 자급제·알뜰폰 확산으로 구매 후 비대면 가입이 늘고 있다.
  • 새 경쟁 구도: 핀테크·디지털 손보사의 DIY형 휴대폰보험, 제조사 케어 프로그램의 비대면 가입이 통신사 부가서비스와 경쟁한다. 통신 3사도 개통 후 30~60일까지 비대면 사후 가입을 허용하는 추세다.
  • 수요 요인: 플래그십 단말가 200만 원대, 디스플레이 수리비 40만~60만 원대로 보험 필요성이 커졌고 사용 주기가 길어졌다.
  • 확장 영역: 중고폰 거래 검수와 수리 청구 단계의 부정 청구 방지로 진단 수요가 번진다.
  • 위 수치와 비중은 대부분 출처 확인 전 추정이다. 근거 확보 계획은 1.4에 둔다.

1.3 고객 페인포인트

고객 페인포인트 필요한 것
디지털 손보사·핀테크 전환율 vs 손해율의 충돌, 서류 심사 비용·지연 무설치 진단, 실시간 자동 판정, 감사 증적
알뜰폰(MVNO) 사후 가입 채널을 열고 싶으나 진단 앱 개발·유지 부담. 글로벌 솔루션은 초기비용·최소 물량 조건이 부담 표준 SDK, 고정비 없는 종량제
중고폰 플랫폼·렌탈사 외관 등급의 주관성으로 분쟁, 보증 상품 사전 검수 비용 객관적 진단 리포트, 보증 연계

1.4 근거 보강 계획 🔧

  • 이탈률 40% 등 핵심 수치의 출처 확보(업계 자료, 고객사 퍼널 데이터)
  • 채널별 가입 비중(오프라인 70~80%, 온라인 15~20%)의 공신력 있는 출처 확보
  • 확보 전에는 본문에서 "추정"으로 표기하고, 확인되면 부록 D에서 확실도를 올린다

솔루션

2.1 제품 개요

  • 한 줄 정의: 링크 클릭 후 약 90초 안에 끝나는 설치 없는 비대면 단말 진단
  • 핵심 가치: ① No-App(이탈 감소) ② 오탐을 줄이는 멀티프레임 비전 ③ 부정 가입을 막는 동적 라이브니스
  • 제공 형태: 고객사 청약 페이지에 임베드하는 Web SDK + 서버 Webhook + 백오피스

2.2 핵심 기능 (MVP 4모듈)

모듈 기능
① 웹 실행환경 브라우저에서 카메라 구동(WebRTC), 브라우저 단 전처리(프레임 선별·흔들림 필터), 외곽선·기울기·거리 가이드 오버레이
② 미러 비전 AI 거울 앞에서 전·후면을 2단계로 스캔, 5~10장 연속 프레임으로 필름 기포·지문·반사와 실제 패널 크랙을 구분, 단색 화면 연속 표출로 데드픽셀 등 점검
③ 안티스푸핑(FDS) 무작위 숫자·색상 시퀀스를 거울 반사와 동기화 검증, 자이로·영상 움직임 대조, 탈옥·루팅·에뮬레이터 점검
④ 하드웨어 진단 터치 그리드 데드존 점검, 단말 모델·해상도·OS 자동 식별, IMEI 확인(다이얼패드 *#06# 화면 캡처 OCR)

2.3 고객 여정

최종 사용자(가입자)

  1. 구매·개통 후 보험사 안내(알림톡/문자) 수신 → 링크 클릭
  2. 브라우저에서 카메라·센서 권한 허용 (안내 화면)
  3. 거울 앞에서 전면 → 후면 스캔, 화면 지시에 따라 기기를 기울임
  4. 터치 그리드 문지르기, 단말 정보 확인
  5. 약 90초 안에 결과 화면(통과 / 재촬영 / 심사 전환)과 청약 단계 복귀

보험사·알뜰폰(고객사)

  1. 청약 페이지에 SDK 삽입, 거래 ID 발급
  2. 진단 완료 즉시 Webhook으로 판정(통과·실패·수동심사)과 위험 점수 수신
  3. 통과 건은 자동 승인, 경계 건은 수동 심사 큐로 이동
  4. 분쟁·손해사정 시 백오피스에서 진단 증적(원본 프레임, 타임스탬프, 센서 로그) 조회

2.4 연동 방식

  • 프론트: JavaScript Web SDK 또는 Iframe 임베드, 화이트라벨링(고객사 톤앤매너)
  • 백엔드: REST API + Webhook(서명 검증), 판정 결과서(PDF)
  • 감사 증적: 진단 원본 프레임·센서 로그를 암호화 저장, 위·변조 방지 해시, 보관 기간은 고객사 정책에 맞춰 설정(안: 3년, 3.4 참고)
  • 연동 일정 목표: 표준 SDK 기준 영업일 기준 2주 내 오픈 [검증 필요]

2.5 한계와 보완책 🔧

한계 보완책

  • 전체 영상을 서버로 보내지 않고 핵심 프레임 약 10장(약 15MB)과 센서·라이브니스 로그(약 0.5MB)만 올려 대역폭과 추론 비용을 줄인다.

시장 분석

4.1 TAM-SAM-SOM

단가 400원 환산. 입력 건수는 가정A15, 글로벌 TAM은 출처 미확인A16.

구분 정의 규모
TAM (참고) 글로벌 단말 진단·수명주기 시장 약 4.5조 원 (미확인)
SAM 국내 보험 진단 34억 + 중고 검수 40억 + 청구 검증 52억 약 126억 원/년 (처리 약 3,150만 건)
SOM 자급제·알뜰폰 비대면 파손보험, 잠재 약 120만 건 중 점유율 30%(Y3) 연 36만 건, 진단료 약 1.4억 원

정합성 정정: 원본은 SOM(연 36~50만 건)과 매출 추정(Y2 보험 75만 건)이 맞지 않았다. 이 문서는 점유율 10% → 25% → 30%A05로 SOM에 맞춰 재계산했다. 보수안 Y3 총 처리 51만 건은 SAM 처리 건수의 약 1.6%다.
